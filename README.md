# Mount Nelson Medical Centre — Apple-style static site

GitHub Pages-ready rebuild concept for Mount Nelson Medical Centre.

## What is included
- Multi-page static HTML/CSS/JS site
- Apple-inspired design: large typography, glass navigation, soft cards, big hero sections
- Pages: Home, Doctors, Services, Patient Info, Fees, Contact, New Patient, Book, Healthdirect, AIR, MyMedicare, Feedback, Lost & Found, Alma Laser, Policies
- Demo image placeholders in `assets/photos/`

## Important image/legal note
Do **not** copy images from Google Search unless the practice owns them or has written permission/licensing. Replace placeholders with:
1. Original practice-owned clinic photos, or
2. Photos downloaded from the practice's own Google Business Profile by an authorised owner, or
3. Properly licensed stock/local photos.

Replace:
- `assets/photos/clinic-hero.jpg`
- `assets/photos/mount-nelson.jpg`

## Publish to GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Source: Deploy from a branch → `main` → `/root`.
5. Save and wait for the Pages URL.

## Before going live
- Confirm all fees, doctors, opening hours and bulk billing rules with the practice.
- Connect demo forms to a compliant form backend.
- Add final privacy policy and clinical disclaimers.
- Replace all placeholder photos with approved images.
